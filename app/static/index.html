How it works

Three steps.
Zero cost.

TrackID is just three free open-source libraries combined: yt-dlp for YouTube metadata and audio, FFmpeg for cutting samples, and ShazamIO for track identification.

01

Read the video

We first check YouTube's chapters and description. If a tracklist already exists, we use it as-is — no audio download needed.

02

Detect transitions

Otherwise, FFmpeg's silencedetect finds the real track transitions. We download the audio once and cache it for future rescans.

03

Identify and group

Samples are hashed and cached, sent to Shazam's public endpoint, and grouped into a timestamped tracklist with original mix tags.

Features

Built for replay, not hype.

Two analysis modes

Quick for casual sets, Thorough for marathon mixes.

Smart caching

The audio and fingerprints are hashed, so rescan jobs never re-download or re-call Shazam for the same sample.

Rescan any window

Click any row to re-identify a section with finer samples. Cancels and resumes supported.

Exports everywhere

Plain text, CSV, JSON, or an M3U playlist that opens in any media player.

Shareable jobs

Each analysis persists in SQLite and can be reopened by anyone with the link.

Cancel anytime

Stop an in-flight recognition with a single click; partial results are kept.

Self-host

Run it on your own machine.

TrackID is a single FastAPI service. Clone it, run docker compose up and you have a private instance with no external dependencies beyond ffmpeg and your machine's network. 

git clone https://github.com/javiservices/trackid
cd trackid
docker compose up --build
# open http://localhost:8000
